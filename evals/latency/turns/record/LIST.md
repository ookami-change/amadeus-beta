# 话轮录音清单

在本目录执行 `python3 -m http.server`，用它打印的本机地址打开 `index.html`。不要直接双击文件，浏览器不给 `file://` 页面麦克风。点「录」再说，点「停」后下载的是 16 kHz 单声道 wav，文件名就是编号。录音不要提交。

第二个人再录时，在页面上方写一个字母，文件名会变成 `b-t01.wav`。
