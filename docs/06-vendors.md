# 06 供应商候选：语音识别、语音合成、大模型

本文给出 M0 实测的候选名单与首轮测试组合。**这是待测名单，不是结论** —— 公开的中文实时语音横评很少，现有数字多为厂商自述，最终以 D1 / D2 在我们自己环境里的实测为准。

资料时间：2026-11。标注"未核实"的条目来自既有认知，本次未能从公开资料确认现状，接入前先看官方文档。

## 0. 先决问题：用户和服务器在哪

这个问题决定首轮名单，因为每一跳跨境网络会吃掉 100–200ms，占延迟预算的四分之一。

- **Claude 不在中国大陆提供服务**。用 Claude 做大脑，智能体服务就要部署在其支持的地区
- 海外语音厂商（ElevenLabs、Deepgram 等）从大陆访问延迟高且不稳定；国内厂商从海外访问同理
- 原则：**语音识别、大模型、语音合成、智能体服务四者尽量在同一地区**，只让用户到智能体这一跳跨地区

因此下面按两条线给候选。若用户主要在大陆，D1 必须把"国内全链路"和"海外节点 + Claude"都测一遍，用数据决定。

## 1. 大模型

### 默认方案：Claude

| 用途 | 模型 | 说明 |
|---|---|---|
| 快脑（每轮应答） | Claude Haiku 5.5 `claude-haiku-5-5` | 低延迟、低成本档。推理档位设为 `low` 或关闭思考，以压低首 token 延迟 |
| 快脑对照组 | Claude Opus 5.5 `claude-opus-5-5`，`low` 档位，另测快速模式 | "强模型开低档"有时在人设稳定性和口语质感上明显胜出，值得用延迟换；由 D1 的数据和试听决定 |
| 慢脑（知识、搜索、深度回忆） | Claude Opus 5.5 + 联网搜索工具 | 异步运行，不占实时预算 |
| 后台（记忆巩固、开场准备） | Claude Opus 5.5 或 Sonnet 5.5，走批处理接口 | 不要求实时，批处理价格减半 |

参考价（每百万 token，输入 / 输出，2026-11 初）：Haiku 5.5 $0.10 / $0.50；Sonnet 5.5 $2 / $10；Opus 5.5 $4 / $20。

对本项目特别有用的两个能力：

- **提示词缓存**：人设文件几千字，每轮都带。缓存后首 token 延迟和成本都显著下降。人设放在最前且保持字节级不变，易变内容（情绪、记忆、时间）放在后面
- **对话中途的系统消息**：每轮注入的情绪状态和检索到的记忆，以系统消息追加到消息列表末尾，而不是改写开头的系统提示词 —— 这样不会让缓存失效

### 国内备选（未核实各家当前版本）

豆包（火山方舟）、通义千问（阿里云百炼）、DeepSeek、Kimi、智谱 GLM。选型时看三点：流式首 token 延迟、长人设下的角色稳定性（会不会聊着聊着变回助手腔）、口语自然度。各取其低延迟档进 D1。

## 2. 语音识别

要求：中文、流式、出中间结果、延迟低；加分项是自带断句判定和情绪 / 笑声等事件检测（可直接喂给倾听行为）。

| 线路 | 候选 | 说明 |
|---|---|---|
| 国内 | 火山引擎 豆包流式语音识别 | 未核实；与豆包语音合成同平台，便于同地区部署 |
| 国内 | 阿里云百炼 Paraformer 实时版 | 未核实 |
| 海外 | Soniox | 厂商自述：面向语音智能体的低延迟中文流式识别，带轮次检测 |
| 海外 | Deepgram | 厂商自述：普通话实时识别延迟低于 300ms |
| 自托管 | FunASR（流式 Paraformer）/ SenseVoice | 开源；SenseVoice 附带情绪与声音事件识别。需要自备 GPU，作为降本和备用方案 |

## 3. 语音合成

**全项目最关键的选型。** 评判顺序：表现力 > 首包延迟 > 其他。

必须具备：流式输出、中文自然。强烈需要：情绪 / 风格控制、笑声叹气等非语言声音、流式文本输入（边生成边合成）、返回字级或音素级时间戳（驱动口型与动作对齐）、声线定制。

| 线路 | 候选 | 说明 |
|---|---|---|
| 国内 | 火山引擎 豆包语音合成大模型 | 未核实；中文对话感口碑好，是首选测试对象 |
| 国内 / 海外 | MiniMax Speech | 未核实；中文情感表现强，有国内和国际两个站点 |
| 国内 | 阿里云百炼 CosyVoice | 官方文档确认支持流式输入与流式输出，面向实时对话场景 |
| 海外 | ElevenLabs | 低延迟档（Flash 系列）与高表现力档（v3 对话版，支持内联音频标签）分属不同模型，两个都测。第三方测得低延迟档首包约 190ms |
| 海外 | Fish Audio | 声线克隆与二次元音色生态活跃；第三方测得首包约 290ms，疑难发音通过率偏低，需重点听中文稳定性 |
| 海外 | Cartesia Sonic | 以低延迟著称，但各方测得的首包数字出入很大（190–450ms）；中文表现未核实 |
| 自托管 | CosyVoice 开源版、GPT-SoVITS | 用于自训练专属声线。CosyVoice 2 自述流式延迟约 150ms 并支持细粒度情感控制 |

声线的长期方向是**自有声线**：用授权的声音素材训练，或请配音演员录制后定制。不克隆任何现有声优的声音。

## 4. 首轮测试组合

D1 / D2 首轮各类取以下几家，其余作为替补：

| | 国内线 | 海外线 |
|---|---|---|
| 语音识别 | 豆包流式识别、阿里 Paraformer 实时版 | Soniox、Deepgram |
| 大模型 | 豆包、通义千问（各取低延迟档） | Claude Haiku 5.5、Claude Opus 5.5 低档位 |
| 语音合成 | 豆包语音合成大模型、MiniMax、CosyVoice | ElevenLabs（两档）、Fish Audio |

需要负责人申请的密钥：火山引擎、阿里云百炼、MiniMax、Anthropic、Soniox 或 Deepgram、ElevenLabs、Fish Audio。只走其中一条线的话，申请对应那一半即可。
