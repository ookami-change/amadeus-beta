# 07 测试服务器

项目专用的测试服务器：腾讯云轻量应用服务器，国内地域。

## 1. 用途

| 阶段 | 跑什么 | 负载 |
|---|---|---|
| M0 | D1 延迟实测、D2 语音合成批量生成 | 主要在等网络，CPU 很轻 |
| M1–M3 | 智能体服务、WebRTC 媒体服务（LiveKit）、Postgres + pgvector、网页静态文件 | 1–3 个并发测试会话 |

识别、大模型、合成都调用云端接口，**服务器上不跑模型，不需要 GPU**。将来如果要自托管 SenseVoice / CosyVoice 训练专属声线，需要另开一台 GPU 云服务器，轻量服务器不提供 GPU。

## 2. 推荐规格

| 项 | 推荐 | 理由 |
|---|---|---|
| 规格 | **4 核 8G** | Postgres、LiveKit、智能体、静态站点、Docker 构建同时运行时，2 核 4G 会吃紧；4 核 8G 留有余量且价差不大 |
| 带宽 | 10M 优先，5M 可以接受 | 对话音频每路不到 0.1M，用不了多少；占带宽的是首次加载 3D 模型（约 10–30MB，5M 带宽下要 20–50 秒）。模型以后可以挪到对象存储 + CDN |
| 系统盘 | 套餐自带的 SSD 即可（通常 100G 以上） | |
| 地域 | **北京** | 火山引擎、阿里云百炼的主要接入点在北方（未核实，见第 4 节） |
| 系统镜像 | Ubuntu 24.04 LTS（或"Docker CE"应用镜像） | |
| 购买时长 | **至少 3 个月，建议 1 年** | 网站备案要求服务器包年包月满 3 个月，见第 3 节 |

价格以官网为准。第三方文章（2026-11）提到的活动价：4 核 8G 5M 约 450 元 / 年（首单）、4 核 8G 10M 约 630 元 / 年（秒杀）。活动价多限新用户、个人认证，**续费价通常明显更高**，下单前看清续费价。

## 3. 一个容易漏的问题：HTTPS 与备案

浏览器只允许在 HTTPS 页面（或 localhost）上使用麦克风，所以从 M1 起，测试页必须用"域名 + HTTPS"访问。而国内服务器用域名对外提供网站，需要先完成 **ICP 备案**：

- 前提：一个域名；服务器包年包月满 3 个月且剩余有效期不少于 1 个月
- 备案通常要一到几周，**建议买完服务器就开始办**，与 M0 并行
- 备案下来之前不影响开发：M0 的 D1、D2 不需要浏览器；需要在浏览器里试时，用 SSH 端口转发把服务映射到本机 localhost

## 4. 买完之后

1. 防火墙放行：22（SSH，限制来源 IP）、80 / 443（备案后）、LiveKit 所需的 UDP 端口段（M1 时由开发给出具体端口）
2. 只用 SSH 密钥登录，关闭密码登录
3. **测连通性**：在服务器上测到各厂商接入点的往返延迟（`curl -w` 计时即可），结果写进 D1 报告。如果明显偏高，换地域比优化代码有效

## 5. 密钥管理

密钥存放在负责人的 1Password 中。规则：

- 为本项目单独建一个保险库（如 `Amadeus-Dev`），只放本项目的密钥
- 为测试服务器建一个**只读、只能访问该保险库**的服务账号（Service Account），服务器上用 1Password CLI 在启动时注入环境变量：`op run --env-file=.env.tpl -- <启动命令>`。`.env.tpl` 里只写引用（`op://Amadeus-Dev/...`），可以入库
- 服务器磁盘上不落明文密钥；服务账号令牌本身按 1Password 的说明保存，泄露时在 1Password 里吊销即可
- 开发者本机同理，用自己的 1Password 账号执行 `op run`
