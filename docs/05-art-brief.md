# 05 美术需求书

面向美术（Grok、Kimi）。本文自成一体，可以整篇直接交给他们；每个需求包（A1–A8）也可以单独拿出来下发。

## 0. 背景（给美术看的一段话）

我们在做一个实时语音对话的二次元角色。她以**全身 3D 模型**站在屏幕里，听用户说话时会看着对方、点头，说话时有口型、手势和表情。产品的核心是"像真人"，所以美术的第一目标是**表演性**：脸要能做出细腻的表情，手和手臂要能自由做动作，而不是一张好看但动不起来的立绘。

角色是 LunaCafe（仓库 `ookami-change/meido-ds`）里的女仆**克劳德**。她已经有成套的立绘和设定，这次的工作不是重新设计，而是**把她改编成适合 3D 表演的版本**，并补齐建模需要的设定图。

不得引入任何第三方作品的角色元素；生成时不要在提示词里使用任何作品名、角色名、画师名。

## 1. 角色设定

### 现有资料（都在 `meido-ds` 仓库）

| 资料 | 路径 |
|---|---|
| 立绘 5 张（normal / smile / shy / troubled / surprised） | `art/portraits/claude/` |
| 立绘的生成工具、模型、提示词、后处理记录 | `art/refs/claude-portrait-normal.md`、`art/refs/claude-expressions.md` |
| 剧情插图（对账、笔记本、门禁、蝴蝶） | `art/cg/claude-*.png` |
| 性格与台词 | `src/data/text/talks.json` 中 `claude` 部分 |

立绘是用 PixAI 的 Tsubaki.3 模型生成的。为保持画风一致，新图优先沿用同一工具和模型，并以 `normal.png` 作为参考图。

### 她是谁

| 项 | 设定 |
|---|---|
| 名字 | 克劳德（文件名里统一用 `claude`） |
| 年龄感 | 成年，20 岁出头。3D 版的体态和脸都要读得出是成年人 |
| 性格 | 话不多，做事一丝不苟，较真；平静、克制、礼貌；说出真心话会害羞 |
| 气质关键词 | 安静、端正、书卷气、温和但有原则 |
| 身高 / 头身 | 约 160cm，6.5–7 头身 |

**情绪幅度小**是她最重要的表演特征：高兴是嘴角一点笑，不高兴是变得更安静。表情设计要在"小幅度"里做出区分，不要做成大喜大怒。

### 必须保留的识别特征

- 亮橘色长卷发
- 头右侧的橘色菊花发饰 + 黑色小缎带
- 琥珀色眼睛
- 配色：米色为主，橘色与黑色为辅，少量金色点缀
- 高领、领口的黑色领巾与菊花胸针
- 菊花纹样作为贯穿元素（刺绣、胸针、书封）
- 一本封面有菊花的棕色皮面书（作为道具，不是一直拿在手里）

### 场景设定决定了服装：打烊之后

Amadeus 里的她是**下班以后**的克劳德 —— 原作里她离开前会"把围裙叠好放在吧台上，叠得方方正正"。所以 3D 版是她摘掉头饰、解下围裙之后的样子。这既符合剧情，也正好去掉了最妨碍动作的几件东西。

| 部位 | 现有立绘 | 3D 版改编 | 原因 |
|---|---|---|---|
| 头饰 | 白色荷叶边女仆头饰 | **去掉**；菊花发饰保留 | 下班了；减少头部物理 |
| 头发 | 及膝长卷发，披散 | **及腰**，保持卷度与体量感；发束归并成较大的几股 | 及膝长发会与裙子、手臂大量穿插，物理模拟难以稳定 |
| 披肩 | 盖住双肩的米色短披肩 | **去掉**，或改为不过肩线的小立领装饰 | 披肩会挡住肩和上臂，抱臂、抬手时必然穿模 |
| 袖子 | 蓬松长袖 + 荷叶袖口 | 上臂保留一点泡泡袖，**前臂收窄**，袖口止于手腕、荷叶边缩小 | 手势是表演重点，手腕和手必须干净露出 |
| 围裙 | 白色荷叶边围裙 | **去掉** | 下班了；少一层布料 |
| 束腰 | 黑色束腰 + 细金链 | 保留，金链可简化 | 识别特征，且贴身不影响动作 |
| 裙子 | 米 / 橘 / 黑多层及踝长裙 | **单层 A 字裙，长度到小腿中段**，用拼色裙片保留三色层次 | 多层长裙是 3D 中最大的穿模来源；露出脚踝也便于看清重心转移 |
| 鞋 | 米色系带短靴 | 保留 | |
| 书 | 双手抱在腰前 | 独立道具，可拿可放 | 双手要腾出来做动作 |

### 为动画服务的硬性约束

这些约束决定模型能不能演戏，优先级高于还原度：

1. **双手完整露出**，手指清晰分开，袖口不过手腕
2. **手臂能抱在胸前、能双手交叠放在身前**（她的习惯姿态）：胸前和上臂没有突出的装饰
3. **飘动物只留头发和裙摆两处**
4. **刘海不遮眉毛**（眉毛是表情的一半）；现有立绘刘海偏长，3D 版要让眉毛可见
5. **轮廓简洁**：剪影靠橘色长发 + 菊花发饰辨认，细节集中在上半身和脸

## 2. 画风

- 现代日系赛璐璐：清晰线条、两到三阶明暗、少量渐变
- 最终要落到 3D 卡通渲染上，所以设计图**不要依赖厚涂光影或复杂材质**来成立 —— 平涂状态下就得好看
- 脸：眼睛偏大但不夸张，鼻子和嘴简化，能承载细微表情

## 3. 需求包

### A1 3D 版改编设计 ｜优先级 P0

- 以 `art/portraits/claude/normal.png` 为基础，按第 1 节的改编表出 **2–3 个方案**，每个方案一张全身正面立像，纯色背景
- 方案间的差异放在未定的几处：头发的收束方式（披散 / 低扎 / 松编）、披肩去留、裙片的拼色方式
- 我们选定一个后再进入 A2 及之后的环节
- **验收**：和现有立绘放在一起，一眼认得出是同一个人；成年感明确；满足全部硬性约束

### A2 三视图 ｜P0，3D 建模的直接依据

- 正面、正侧面、背面，另加一张 3/4 侧面
- **A-pose**（双臂自然下垂外展约 45°）、表情中性、双脚平行
- 正交视角、无透视、无光影、纯白或中灰背景；各视图身高对齐、比例严格一致
- 另附：头部正面和侧面特写各一张（同样无透视）
- **验收**：各视图间发型、服装结构、配饰位置逐项对得上，没有"正面有背面没有"的细节

### A3 表情设定 ｜P0

同一角度（正面略偏）的头像，每个表情一格。分两组：

**情绪表情**（对应系统里的表情词表）。现有立绘已有其中 5 个，可直接作为基准；所有表情都按"幅度小"来画。

| 标识 | 表情 | 要点 | 现有立绘 |
|---|---|---|---|
| `neutral` | 平静 | 默认脸，嘴角极轻微上扬，端正 | `normal` |
| `smile` | 微笑 | 克制的、真心的 | `smile` |
| `joy` | 开心 | 她最大幅度的笑：眼睛弯起，嘴微张，不露齿大笑 | — |
| `shy` | 害羞 | 脸红、视线移开、嘴抿着 | `shy` |
| `troubled` | 为难 | 眉头微蹙、眉尾下垂，嘴角略收 | `troubled` |
| `surprised` | 惊讶 | 眼睁大、嘴微张，幅度不大 | `surprised` |
| `serious` | 较真 | 眉微压、目光专注，嘴闭紧。纠正别人、对账时的脸 | — |
| `sad` | 难过 | 垂眼，比 `troubled` 更安静，克制不哭 | — |
| `thinking` | 思考 | 视线上移或侧移，嘴微抿 | — |
| `curious` | 好奇 | 眼睛略睁大、发亮，头微偏 | — |
| `sleepy` | 困倦 | 眼皮沉，强撑着端正 | — |

**口型与眼部**（做 3D 表情形变的参考）

- 口型 5 个：あ / い / う / え / お
- 眼：闭眼、半闭、左眼单眨、右眼单眨；视线上 / 下 / 左 / 右

**验收**：遮住下半张脸仅看眉眼，仍能分辨出各个情绪；各格脸型、五官位置一致；与现有 5 张立绘的对应表情不矛盾

### A4 姿态与手势参考 ｜P1

全身线稿或简单上色即可，用于指导动作制作，不追求精细。

- **基础站姿 6 个**：端正站立（双手交叠于身前，她的默认姿态）、重心偏一侧、双手抱书于腰前、单手抚胸口、双手背后、身体略前倾
- **手势 12 个**：单手托下巴思考、食指竖起讲解、掌心向上示意、轻轻摆手否定、扶额、把头发别到耳后、掩嘴轻笑、翻书、低头看书、小幅挥手打招呼、别过脸、微微欠身
- 她的动作幅度小而准，手肘贴近身体，没有大开大合的动作
- **验收**：每个姿态的重心和手部形状清楚，动画师能照着摆出来

### A5 细节与色指定 ｜P1

- 色板：每个部位的固有色、暗部色，给出十六进制色值
- 服装结构分解：外套、内搭、下装、鞋分别的正背面
- 配饰单独的多角度图：菊花发饰与缎带、领巾与胸针、书
- 手部特写：正反面，指甲形状

### A6 场景背景 ｜P1

**打烊后的 LunaCafe。** 店里的灯关了一半，椅子收好，吧台上放着叠好的围裙和她的书。空间布局参考 `meido-ds` 的 `art/scenes/cafe-night.png` 与 `art/refs/cafe-scene.md`，但那是像素画，这里要画成与立绘同一画风的插画背景（可参考 `art/cg/claude-ledger.png` 的室内表现）。

- 视角：平视，画面中央偏下留出空地给角色站立，吧台在她身侧或身后；角色不出现在背景里
- 规格：横版 16:9（3840×2160）与竖版 9:16（2160×3840）各一套，构图分别设计而不是裁切
- **同一场景 4 个时段**，只变光线，物件位置必须一致 —— 系统会按真实时间切换：
  - 傍晚：刚打烊，窗外是暮色，店内灯还亮着大半
  - 深夜：只留吧台上方的几盏灯，窗外全黑（**主时段，最先做**）
  - 清晨：开店前，晨光从窗户斜射进来，灯未开
  - 白天：休息日的空店，自然光
- 景深略虚，不抢角色
- **验收**：四个时段叠在一起物件不错位；角色站位区域没有杂乱物件

### A7 品牌与界面元素 ｜P2

- 标志：文字标 "Amadeus" + 一个图形标，深浅两种底色版本，矢量（SVG）
- 应用图标：1024×1024
- 界面风格参考图 1–2 张：界面极简，只有麦克风状态、设置入口、记忆查看入口；不要聊天气泡式布局

### A8 3D 模型 ｜P0，见第 5 节的说明

规格（VRM 1.0）：

| 项 | 要求 |
|---|---|
| 格式 | VRM 1.0（`.vrm`），另附源文件 |
| 面数 | 总三角面 ≤ 70,000 |
| 材质 | MToon 卡通材质，材质数 ≤ 8；贴图 2048×2048 以内 |
| 骨骼 | VRM Humanoid 标准骨骼全套，**含全部手指骨**、上胸骨、双眼骨 |
| 表情 | VRM 标准预设全套（happy / angry / sad / relaxed / surprised，aa / ih / ou / ee / oh，blink / blinkLeft / blinkRight，lookUp / Down / Left / Right），另加自定义：`shy`、`troubled`、`serious`、`thinking`、`curious`、`sleepy` |
| 物理 | 头发、裙摆、发饰缎带设置弹簧骨；躯干、手臂、腿设置碰撞体防止穿模 |
| 道具 | 书做成独立物体，可挂接到手部骨骼，默认隐藏 |
| 视线 | 设置 LookAt，眼球转动范围自然 |
| 初始姿态 | T-pose（VRM 规范要求），面向 +Z |

**验收**：在 three-vrm 官方查看器中能正常加载；逐个拨动表情无破面；双手交叠于身前、抱臂、举手过头三个姿势下无严重穿模；头发不穿过手臂和裙子。

## 4. 交付规范

- 位图：PNG，角色类图透明或纯色背景，长边 ≥ 2048 像素
- 命名：`{包号}_{内容}_{版本}.png`，例：`A2_turnaround_front_v1.png`、`A3_expr_serious_v2.png`、`A6_bg_landscape_night_v1.png`
- 存放：概念与设定图放 `assets/concept/`，背景放 `assets/backgrounds/`，模型放 `assets/avatar/`
- 每次交付附一句说明：用了什么工具、是否经过人工修改
- 版权：确认所用工具的条款允许对产出进行再分发；不使用任何带作品名 / 角色名 / 画师名的提示词

## 5. 分工

按两者的能力，建议这样分：

- **Grok**（图像生成）：A1、A2、A3、A4、A5、A6 的出图。现有立绘是用 PixAI 生成的，换工具后画风容易漂移，每批产出都要和 `normal.png` 并排比对
- **Kimi**（文字与结构化输出）：把第 1 节设定扩写成给 Grok 的分镜级提示词；对 Grok 的产出做一致性核对（三视图是否对得上、表情是否同一张脸）；A7 的 SVG 标志；整理色板

**A8 的 3D 模型由 Kimi 制作**（2026-11-21 起，原计划由负责人用 VRoid Studio 制作）。完整需求、验收标准和交付物见 [`docs/guides/vroid-claude.md`](guides/vroid-claude.md)，两者冲突时以本文为准。建模依据 A2 三视图和 A3 表情设定，所以 A2、A3 的质量直接决定建模质量：三视图各角度必须严格对得上，表情要画清眉、眼、嘴各自的形状。

自定义表情（`shy`、`serious` 等）超出 VRM 标准预设，能做则做，做不了记入第二版，不卡交付。在定制模型到位之前，开发侧先用公开的示例 VRM 模型推进。模型交付后由架构师按规格书 §5 验收，再由 Cursor 替换演示里的示例模型并做真机测试。
