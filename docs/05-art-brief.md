# 05 美术需求书

面向美术（Grok、Kimi）。本文自成一体，可以整篇直接交给他们；每个需求包（A1–A8）也可以单独拿出来下发。

## 0. 背景（给美术看的一段话）

我们在做一个实时语音对话的二次元角色。她以**全身 3D 模型**站在屏幕里，听用户说话时会看着对方、点头，说话时有口型、手势和表情。产品的核心是"像真人"，所以美术的第一目标是**表演性**：脸要能做出细腻的表情，手和手臂要能自由做动作，而不是一张好看但动不起来的立绘。

所有产出必须**完全原创**：不得参考或接近任何现有作品的角色，生成时不要在提示词里使用任何作品名、角色名、画师名。

## 1. 角色设定

| 项 | 设定 |
|---|---|
| 暂用名 | 待定（文件名里统一用 `heroine`） |
| 年龄 | 成年，21 岁左右。体态和脸都要读得出是成年人 |
| 身份 | 天才型研究者。她知道自己是由记忆数据构成的 AI，并对此坦然 |
| 性格 | 聪明、好奇、嘴硬心软；讲到专业话题会兴奋，被调侃会炸毛 |
| 气质关键词 | 理性、利落、有点傲、偶尔露出孩子气 |
| 身高 / 头身 | 约 160cm，6.5–7 头身（不要 Q 版，也不要写实比例） |

### 外形方向（A1 阶段可在此基础上发散）

- **头发**：深色（藏青 / 墨蓝）中短发，长度不过肩；内层有一抹亮色挑染（青色系）。不要超长发、不要大面积遮脸的刘海 —— 会挡表情、物理模拟也难做
- **眼睛**：琥珀 / 金色系，瞳孔里有一圈很淡的环状高光纹，暗示"数字存在"。这是全身唯一的科幻记号，要克制
- **服装**：日常 + 一点研究者气质。例如宽松针织开衫或短外套 + 衬衫 + 及膝以上的下装 + 短靴。颈上可挂一副耳机作为标志物
- **色彩**：主色深蓝 / 米白，点缀色青色，全身不超过 4 个主要颜色
- **明确回避**：红棕色长发、白大褂 + 领带的组合、任何让人联想到现有知名角色的整体搭配

### 为动画服务的硬性约束

这些约束决定模型能不能演戏，优先级高于好看：

1. **双手完整露出**，手指清晰分开。不要手套、不要长过手腕的袖口
2. **手臂能抱在胸前、能叉腰**：上臂和胸前不要有厚重或突出的装饰
3. **没有大面积飘动物**：不要长裙、披风、长飘带、及腰长发
4. **脸部干净**：不要遮住眉毛的刘海（眉毛是表情的一半）、不要眼镜（会挡眼神；如要可作为可拆卸配件）
5. **轮廓简洁**：剪影一眼能认出，细节集中在上半身和脸

## 2. 画风

- 现代日系赛璐璐：清晰线条、两到三阶明暗、少量渐变
- 最终要落到 3D 卡通渲染上，所以设计图**不要依赖厚涂光影或复杂材质**来成立 —— 平涂状态下就得好看
- 脸：眼睛偏大但不夸张，鼻子和嘴简化，能承载细微表情

## 3. 需求包

### A1 角色概念设计 ｜优先级 P0

- 出 **3 个差异明显的方案**，每个方案一张全身正面立像，纯色背景
- 三个方案在发型、服装轮廓、配色上拉开差距，都要满足第 1 节的硬性约束
- 我们选定一个（或混搭）后再进入 A2 及之后的环节
- **验收**：成年感明确；剪影可辨识；不与任何现有角色相似；满足全部硬性约束

### A2 三视图 ｜P0，3D 建模的直接依据

- 正面、正侧面、背面，另加一张 3/4 侧面
- **A-pose**（双臂自然下垂外展约 45°）、表情中性、双脚平行
- 正交视角、无透视、无光影、纯白或中灰背景；各视图身高对齐、比例严格一致
- 另附：头部正面和侧面特写各一张（同样无透视）
- **验收**：各视图间发型、服装结构、配饰位置逐项对得上，没有"正面有背面没有"的细节

### A3 表情设定 ｜P0

同一角度（正面略偏）的头像，每个表情一格。分两组：

**情绪表情**（对应系统里的表情词表）

| 标识 | 表情 | 要点 |
|---|---|---|
| `neutral` | 平静 | 默认脸，略带一点冷淡 |
| `smile` | 微笑 | 克制的、真心的 |
| `joy` | 开心 | 露齿笑，眼睛弯起 |
| `smug` | 得意 | 单侧嘴角上扬，眼神向下看人 |
| `annoyed` | 不耐烦 | 半睁眼、眉微皱 |
| `angry` | 生气 | 炸毛式的，不是凶狠 |
| `embarrassed` | 害羞 / 别扭 | 脸红、视线移开、嘴抿着 |
| `surprised` | 惊讶 | 眼睁大、嘴微张 |
| `sad` | 难过 | 眉尾下垂，克制不哭 |
| `thinking` | 思考 | 视线上移或侧移，嘴微噘 |
| `curious` | 好奇 | 眼睛发亮、身体前倾感 |
| `sleepy` | 困倦 | 眼皮沉、打哈欠 |

**口型与眼部**（做 3D 表情形变的参考）

- 口型 5 个：あ / い / う / え / お
- 眼：闭眼、半闭、左眼单眨、右眼单眨；视线上 / 下 / 左 / 右

**验收**：遮住下半张脸仅看眉眼，仍能分辨出各个情绪；各格脸型、五官位置一致

### A4 姿态与手势参考 ｜P1

全身线稿或简单上色即可，用于指导动作制作，不追求精细。

- **基础站姿 6 个**：自然站立、重心偏一侧、抱臂、单手叉腰、双手背后、身体前倾凑近
- **手势 12 个**：单手托下巴思考、食指竖起讲解、摊手、摆手否定、指向对方、扶额、拨头发、捂嘴笑、双手握拳（兴奋）、挥手打招呼、别过脸、耸肩
- **验收**：每个姿态的重心和手部形状清楚，动画师能照着摆出来

### A5 细节与色指定 ｜P1

- 色板：每个部位的固有色、暗部色，给出十六进制色值
- 服装结构分解：外套、内搭、下装、鞋分别的正背面
- 配饰（耳机等）单独的多角度图
- 手部特写：正反面，指甲形状

### A6 场景背景 ｜P1

她所在的空间：一间有生活痕迹的个人研究室 / 书房（书架、桌面设备、窗）。

- 视角：平视，画面中央偏下留出空地给角色站立；角色不出现在背景里
- 规格：横版 16:9（3840×2160）与竖版 9:16（2160×3840）各一套，构图分别设计而不是裁切
- **同一场景 4 个时段**：清晨、白天、黄昏、深夜（深夜以台灯和屏幕光为主）。四张的物件位置必须一致，只变光线 —— 系统会按真实时间切换
- 画风与角色统一，景深略虚，不抢角色
- **验收**：四个时段叠在一起物件不错位；角色站位区域没有杂乱物件

### A7 品牌与界面元素 ｜P2

- 标志：文字标 "Amadeus" + 一个图形标，深浅两种底色版本，矢量（SVG）
- 应用图标：1024×1024
- 界面风格参考图 1–2 张：界面极简，只有麦克风状态、设置入口、记忆查看入口；不要聊天气泡式布局

### A8 3D 模型 ｜P0，见第 5 节的说明

规格（VRM 1.0）：

| 项 | 要求 |
|---|---|
| 格式 | VRM 1.0（`.vrm`），另附源文件 |
| 面数 | 总三角面 ≤ 70,000 |
| 材质 | MToon 卡通材质，材质数 ≤ 8；贴图 2048×2048 以内 |
| 骨骼 | VRM Humanoid 标准骨骼全套，**含全部手指骨**、上胸骨、双眼骨 |
| 表情 | VRM 标准预设全套（happy / angry / sad / relaxed / surprised，aa / ih / ou / ee / oh，blink / blinkLeft / blinkRight，lookUp / Down / Left / Right），另加自定义：`smug`、`annoyed`、`embarrassed`、`thinking`、`curious`、`sleepy` |
| 物理 | 头发、外套下摆、耳机线设置弹簧骨；设置碰撞体防止穿模 |
| 视线 | 设置 LookAt，眼球转动范围自然 |
| 初始姿态 | T-pose（VRM 规范要求），面向 +Z |

**验收**：在 three-vrm 官方查看器中能正常加载；逐个拨动表情无破面；抱臂、叉腰、举手过头三个极限姿势下无严重穿模。

## 4. 交付规范

- 位图：PNG，角色类图透明或纯色背景，长边 ≥ 2048 像素
- 命名：`{包号}_{内容}_{版本}.png`，例：`A2_turnaround_front_v1.png`、`A3_expr_smug_v2.png`、`A6_bg_landscape_night_v1.png`
- 存放：概念与设定图放 `assets/concept/`，背景放 `assets/backgrounds/`，模型放 `assets/avatar/`
- 每次交付附一句说明：用了什么工具、是否经过人工修改
- 版权：确认所用工具的条款允许对产出进行再分发；不使用任何带作品名 / 角色名 / 画师名的提示词

## 5. 分工建议与一个需要确认的问题

按两者的能力，建议这样分：

- **Grok**（图像生成）：A1、A2、A3、A4、A5、A6 的出图
- **Kimi**（文字与结构化输出）：把第 1 节设定扩写成给 Grok 的分镜级提示词；对 Grok 的产出做一致性核对（三视图是否对得上、表情是否同一张脸）；A7 的 SVG 标志；整理色板

**需要确认：A8 的 3D 模型由谁来做。** 图像生成工具产出的是 2D 图，而系统需要的是带骨骼和表情形变的 3D 模型，这一步目前两者都不能直接完成。可行的路径：

1. **VRoid Studio 手工制作**（推荐作为第一版）：免费，照着 A2 / A3 捏，一个熟悉工具的人约 1–3 天，直接导出合规的 VRM。需要有个人来操作
2. **图生 3D 工具 + 自动绑骨**：速度快，但二次元脸部质量和表情形变目前通常达不到要求，可以试但不要押注
3. **外包给 VRM 模型师**：质量最好，适合正式版

在定制模型到位之前，开发侧会先用公开的示例 VRM 模型推进，不会被美术进度卡住。
